# BigData-NTI

A collection of Big Data and Data Engineering projects developed during the NTI training program. This repository contains hands-on implementations and experiments using Hadoop ecosystem technologies, distributed storage, and data processing frameworks.

## 📌 Overview

This project focuses on building and understanding Big Data systems, including:

- Hadoop Distributed File System (HDFS)
- MapReduce
- YARN
- Apache Hive
- Apache Spark
- Distributed data storage and processing concepts

The goal is to gain practical experience with large-scale data processing and cluster-based architectures.
